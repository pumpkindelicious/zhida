# 智搭 👗

你的私人穿搭助手，根据天气、身材、肤色，推荐今天穿什么。

## ✨ 功能特色

### 🌤 智能天气推荐
- 自动获取当地天气，根据温度推荐穿搭
- 叠穿建议，中午热了脱一层就好
- 雨天提醒带伞、降温提醒加衣服

### 👚 智能衣橱管理
- 7大分类：外套、上衣、下装、鞋子、包包、袜子、配饰
- 照片上传 + 自动抠图（白底图）
- 自动提取衣服主色
- 自动推断衣服属性：版型、厚度、季节、材质
- 码数根据身高体重自动推荐
- 搜索功能，快速找到衣服

### 🎨 肤色诊断
- 四点取色法，分析四季型肤色
- 推荐适合你的颜色和穿搭

### 🎨 自由搭配编辑器
- 画布自由拖拽衣服
- 图层上下调整、旋转、缩放
- 保存搭配，随时查看

### 📊 衣橱色彩统计
- 环形图展示衣橱颜色占比
- 结合肤色，推荐适合的颜色
- 一键重新测肤色

### 📅 经期记录
- 日历记录经期，贴心提醒

## 🚀 快速开始

直接打开 `index.html` 就能用，不需要安装任何东西。

## 🛠 技术栈

- 纯前端 HTML + CSS + JavaScript
- 天气 API：wttr.in（免费，无需 key）
- 数据存储：localStorage（所有数据只存在你自己浏览器里）
